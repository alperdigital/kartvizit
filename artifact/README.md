# Kartvizit Artifact prototipi

`npm run build:artifact` tek dosyalık HTML üretir. Varsayılan giriş gerçek sağlayıcı bağlamaz: görünür sohbet-JSON alternatifi ve geçici arşiv kullanır. TypeScript adaptörleri yalnızca doğrulanmış Claude host yetenekleriyle bağlamak içindir. Yerel uygulama bir Claude hesabının veya Personal Storage'ın doğrulandığına dair kanıt değildir.
