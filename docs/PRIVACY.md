# Veri sınırları

Yerel OCR ve yerel arşiv cihaz içindedir. İsteğe bağlı tam PWA yedeği fotoğraf/ham OCR içerebilir. Claude aktarım dosyası bunları çıkarır; ayrıştırılmış iletişim bilgileri yine kişisel veri olabilir. İndirme, pano ve sistem paylaşımı kullanıcı tarafından başlatılır. Silme taşınmaz.

Claude içinde veya Claude sohbetinde göndermeyi seçtiğiniz fotoğraf Anthropic tarafından işlenir. Fotoğrafı Kartvizit arşivine yazmamak, hizmet tarafında saklama olmaması anlamına gelmez. Kartvizit oturum çerezi, API anahtarı veya şifre tutmaz. Shared Storage kullanmaz. Personal Storage ve ikinci hesap izolasyonu, hedef ortamda test edilmeden üretime açılmaz.
