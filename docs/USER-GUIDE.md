# Kullanım

**Tara** bölümünden **Claude ile Tara**, **Cihazda Tara** veya **Manuel ekle** seçin. Cihazda Tara, OCR kaynakları indirildikten sonra bağlantı gerektirmez. Claude bağlantısı yalnızca yapılandırıldığında ve cihaz çevrimiçi göründüğünde açılır. Giriş gerektiğine Claude karar verir.

**Claude aktarımı** bölümünde v1 JSON dosyası seçin veya metni yapıştırıp inceleyin. Aynı kimlik veya benzer iletişim bilgileri varsa değişiklikleri kontrol edin. Kayıtları koruyabilir, gelen bilgiyi kullanabilir, birleştirebilir, ayrı kart oluşturabilir, atlayabilir veya aktarımı iptal edebilirsiniz. Arşive aktar dediğinizde rapor görünür. Boş gelen alanlar ve fotoğrafsız aktarım mevcut yerel verileri istemeden silmez.

Tüm kartlar için Claude aktarımı panelinden, seçili kartlar için arşivin **Dışa aktar** menüsünden **Claude JSON**’u seçin. Tam JSON yedeği ayrı bir seçenektir.
